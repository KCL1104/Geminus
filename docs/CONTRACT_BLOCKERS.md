## Method and confidence labels

Three read-only reviews cross-checked the derived documents, schemas, OpenAPI, SQL, fixtures and original report page numbers for IR/Simulation, API/DB/Security and AI/Import respectively; the lead agent then spot-checked them. Each item is labelled with an evidence level:

- **Measured**: reproduced by a command this time (disposable PostgreSQL 16.15, tool execution).
- **Verified**: the lead agent personally re-read the cited line numbers; the content matches.
- **Review-reported**: reported by a read-only review with line numbers, not yet re-verified line by line by the lead agent; please confirm these first during review.

The "Covered" column says whether an existing D-xxx already records this gap; NEW means the decisions register does not cover it yet, and a human decides whether to promote it to a new D-entry.

## 2. Findings and decisions taken in the slice

1. **The job ends before the investigation, in one transaction (`handler.Ender`).** A3 §5 (2) requires the worker's Finish to end the job first; `handler.Run.Finish` runs its fn before the job's end. Adding `FinishThen` (fn, the end, then after) keeps the existing interface and every handler unchanged.
2. **jsonb gives the ledger back in its own form.** The stored arguments and observations come back with jsonb's spacing and member order, which A5's transcript check (`Decode` canonical equals stored) refused: the first DB run ended both real-loop tests `ai_failed` (§3). The mirror (`stepOf`) now restores RFC 8785 form; the in-memory test ledger prints its JSON as jsonb does, so the unit tests hold the same shape.
3. **Tools are `InvokableTool`s over the registry, not `InferTool`s.** H-061 §5.3 says InferTools with injected bodies; `InferTool` would infer a second argument schema from Go types. The agent's tools carry name and description only; the input schema the model is sent is the registry's projection in the turn's context (one schema, A5), and the planner's tripwire refuses tools with parameters.
4. **The worker also gates the planner model.** `INVESTIGATION_PLANNER_MODELS` (the API's A7 setting of the same name) defaults to `muse-spark-1.3` here too; an investigation naming Muse Wonder 1.0 ends `ai_failed` before any call unless the worker lists it (H-061 §14's default off, defence in depth). PROPOSED: A7 reads the same variable; the coordinator sets both after a recorded pass.
5. **Planner turns are counted from the spend ledger and the attempt.** The 20-turn cap: the investigation's investigator reservations at the attempt's start (`PlannerTurns`) plus this attempt's turns (a turn refused before any I/O is not counted). With the unmetered fake, only the attempt's are counted; the database's ceiling trigger stays the backstop (a 21st reservation is `quota_exceeded`, which ends `spend_cap`).
6. **The last attempt ends the investigation itself.** A turn that keeps failing (or an internal error) fails the attempt as retryable so the job resumes; on the job's 5th attempt the handler ends `ai_failed` with its own `investigation.end`, so that end has its worker event. An attempt lost to a lapsed lease on the 5th attempt still ends through `follow_investigation_job` (A3) with no worker event (risk, §6).
7. **A proposal's index is counted from the ledger** (the done propose calls up to it, the order the database assigns it in): the store layer does not read the label columns before A4.
8. **The rules line sits after the domain rules, before the research template**, so a research call keeps the research template last; its own header names `investigation-rules-1`.
9. **One W1 test assertion is replaced by H-061's rule, not weakened.** `TestTheLanesSplitTheBuildsHandlers` asserted that "a type added later (an investigation's, say)" goes to the rest lane; H-061 §5.1 puts investigations on agent lanes only. The assertion now uses `import_mapping` for a later type, and `TestTheAgentLanesRunOnlyInvestigations` asserts the investigation handler is on agent lanes and on no sim or rest lane.
10. **Tests first, where the slice allowed.** The config and lanes tests and the rules-line test were written and run red first (§3). The planner, agent and handler were written with their tests; mutation probes (§3) show each guarded rule fails its test when removed, and one survivor (an observation written by another attempt) led to a new test.

## 6. Risks

- **Worker capacity.** Each agent lane is held by one investigation for up to 20 minutes, in the same process as the sim and rest lanes (no GOMEMLIMIT); two agent lanes on one replica.
- **A lost 5th attempt ends without a worker event.** The reaper fails the job and `follow_investigation_job` ends the investigation `ai_failed`; no `investigation.end` is written for it (§2 (6)).
- **Poll load.** Each running investigation reads its row (and while a call waits, its ledger) every 500 ms, and a child every second, each a short transaction holding the job's row lock.
- **The planner turn count across attempts relies on the spend ledger** (metered live), so with the fake it is per attempt only; the database's ceiling and turn trigger stay the backstop.
- **Observation shapes are the worker's.** The candidate figures A7 serves must equal these observations' (H-061 §10: a test asserts it, A7's).
- **Merge contention**: `internal/worker/worker.go` and `handler.go` (any loop change), `cmd/worker/*.go` and `internal/config/worker.go` (A7's config, W-slices), `internal/proposals/generator/generator.go` and `internal/analyses/analyzer/analyzer.go` (E2, E3), `internal/ai/aicontext` (E-slices), `internal/audit/audit.go` (A4, A7), `deploy/railway/variables.json` and `scripts/check_deploy.py` (A7, A9), `docs/runbooks/deploy.md`, `Makefile`.
